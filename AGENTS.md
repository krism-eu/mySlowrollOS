# Antigravity Agent Guidelines for mySlowrollOS

## Project Purpose
This repository defines a personal, reproducible openSUSE Slowroll / Plasma Wayland workstation installer profile (using stock Agama 24) and the `atomic-update` system with Btrfs/Snapper snapshot recovery.

---

## Strict Invariants and Prohibitions

1. **Never edit generated files directly**:
   - `agama/profile-final.jsonnet` is generated by `python3 agama/generate-profiles.py`.
   - `obs/criscore1/criscore1.spec` is generated by `python3 core/generate-criscore-spec.py` from `core/protected.seed` and `obs/criscore1/criscore1.spec.in`.
   Always edit the source templates/seeds and regenerate.

2. **Asset Revision Pinning Workflow**:
   - When modifying files in `myslowroll-policy/` or shell scripts in `agama/`:
     1. Stage and commit the asset changes in Git first.
     2. Obtain the commit SHA (`git rev-parse HEAD`).
     3. Run: `python3 agama/generate-profiles.py --assets-revision <COMMIT_SHA>`
     4. Verify drift: `python3 agama/generate-profiles.py --check`
     5. Stage and commit `agama/assets-revision` and `agama/profile-final.jsonnet`.

3. **Installer Safety**:
   - Do **not** pre-populate storage, partitions, disks, or credentials in Agama profiles. The installer must remain interactive for disks and user creation.
   - YaST packages belong strictly in `agama/install-only-packages.txt`. They must never be added as hard `Requires` in `criscore` or workstation specs, ensuring future Slowroll updates are never blocked if YaST modules are retired upstream.

## Mandatory Verification Suite
Before proposing or committing changes, run and ensure 100% pass:

```bash
# 1. Spec & Profile generation and drift checks
python3 core/generate-criscore-spec.py --check
python3 agama/generate-profiles.py --check

# 2. Syntax validation
bash -n atomic-update/atomic-update-5.7.1.sh
for s in agama/*.sh agama/tests/*.sh atomic-update/tests/*.sh; do bash -n "$s"; done

# 3. Unit and regression self-tests
bash agama/init-firstboot.sh --self-test
bash agama/post-chroot-boot-policy.sh --self-test
bash atomic-update/tests/ci-regression.sh

# 4. ShellCheck linting (severity error)
shellcheck --severity=error atomic-update/atomic-update-5.7.1.sh atomic-update/tests/*.sh agama/*.sh agama/tests/*.sh
```

## Environment Notes
- Antigravity / VS Code runs inside a Flatpak container (`org.freedesktop.platform`).
- Host OS is openSUSE Tumbleweed-Slowroll.
- System-level operations (e.g. `zypper`, `rpm`, `snapper`, `btrfs`) must be executed on the host using `flatpak-spawn --host <command>`.
